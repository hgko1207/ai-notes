# Claude Code 9월 업데이트 — 5시간 한도 유연화, 클라우드 작업 정식 출시, 플러그인 마켓

> 한 줄 요약: Claude Code가 5시간 한도에 걸려도 작업을 자연스럽게 마무리하게 바뀌었고, 클라우드 작업이 정식 출시되며 최대 $250 크레딧을 주고, 플러그인은 앱 스토어처럼 제출·심사·통계 확인까지 가능해졌습니다.

## 핵심 요약
- **5시간 한도 유연화**: 한도 도달 시 작업을 뚝 끊지 않고 적절한 중단 지점까지 마무리
- **주간 한도에서 소량 차감**: 마무리에 필요한 소량은 주간 한도에서 가져다 씀
- **클라우드 작업 정식 출시**: 리서치 프리뷰 종료, 출시 기념 크레딧 **Pro $100 / Max $250**
- **플러그인 마켓플레이스**: 제출 → 보안 스캔 → 심사 → 사용 통계(퍼널)까지 앱 스토어와 유사

## 본문

### 1. 5시간 사용 한도 — "갑자기 끊기지 않게"

| 구분 | 이전 | 이후 |
|------|------|------|
| 한도 도달 시 | 편집 도중 즉시 중단 | 적절한 **중단 지점(Breakpoint)**을 찾을 때까지 조금 더 실행 |
| 추가 사용분 | — | 주간 한도에서 **소량의 고정 할당량** 차감 |

코드를 반쯤 고친 상태로 멈춰서 망가진 파일이 남는 문제가 줄어듭니다. 한도 운영이 훨씬 유연해졌다고 볼 수 있습니다.

### 2. 로컬 vs 클라우드 작업 — 클라우드 정식 출시

Claude 작업을 실행할 때 **로컬**(내 컴퓨터)과 **클라우드**(Anthropic 서버의 격리된 환경) 중 선택할 수 있습니다. 리서치 프리뷰였던 클라우드 실행이 정식 버전으로 공개됐습니다.

| 요금제 | 출시 기념 크레딧 |
|--------|----------------|
| Pro | **$100** |
| Max | **$250** |

- 크레딧은 직접 **청구(Claim)** 해야 받을 수 있습니다
- 간단하거나 오래 걸리는 작업을 클라우드에 맡겨 두고 내 컴퓨터는 자유롭게 쓰는 방식이 좋습니다

### 3. Claude 플러그인 — 앱 스토어처럼

플러그인은 Skills, MCP 서버, 명령어 등을 하나로 묶어 배포하는 단위입니다. 이번 업데이트로 설치가 쉬워졌고, 개발자 쪽 기능이 크게 늘었습니다.

```
플러그인 제작 (Skills + MCP 등 결합)
   ↓
제출
   ↓
보안 스캔 (앱 스토어 심사처럼)
   ↓
승인 → 공개
   ↓
사용 현황·퍼널 통계 확인
```

- **리뷰 진행 상황 추적** 가능
- **퍼널(Funnel)** 형태로 설치·사용 흐름을 볼 수 있어 실제 사용량을 파악할 수 있습니다

영상에서는 "기능의 단위가 **앱에서 플러그인으로** 이동할 것"이라는 전망을 내놓았습니다.

## 실전 활용 / 팁
- **크레딧 먼저 청구하세요**: Pro/Max 사용자라면 클라우드 크레딧을 잊지 말고 받아 두세요
- **긴 작업은 클라우드로**: 리팩토링·테스트 보강처럼 오래 걸리는 작업을 클라우드에 보내고 로컬에서는 다른 작업을 진행
- **반복 워크플로우는 플러그인화**: 팀에서 자주 쓰는 Skills·MCP 조합을 플러그인으로 묶어 배포해 보세요. 사용 통계로 효과도 확인할 수 있습니다

## 마무리
이번 업데이트는 "사용자 불편 해소(한도)"와 "생태계 확장(클라우드·플러그인)" 두 축으로 정리됩니다. 특히 플러그인 마켓플레이스는 Claude를 하나의 **플랫폼**으로 만드는 움직임으로, 앞으로 개인 개발자가 플러그인을 만들어 배포하는 흐름이 활발해질 것으로 보입니다.
