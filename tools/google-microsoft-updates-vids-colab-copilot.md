# 구글·마이크로소프트 업데이트 — Gemini 앱 연동 13종, Google Vids 무료, Colab GPU, Copilot Autopilot

> 한 줄 요약: Gemini가 Adobe·Squarespace 등 13개 앱과 연결되고, Google Vids는 무료 요금제에서도 AI 영상을 만들 수 있게 됐으며, Colab이 Google AI 요금제에 통합되고, Microsoft Copilot에는 클라우드 코딩 에이전트 Autopilot이 추가됐습니다.

## 핵심 요약
- **Gemini 앱 연동 13종 추가**: Adobe, Squarespace 등 유명 서비스 안에서 AI를 바로 사용
- **Google Vids**: PPT에 어울리는 비즈니스 설명 영상 제작, **Gemini Omni 1.1 Flash** 사용, 무료 요금제 지원
- **Google Colab → Google AI 요금제 통합**: 구독자도 T4 등 GPU 사용 가능
- **Copilot 개편**: 워크스페이스가 홈으로 통합, Claude Code 같은 클라우드 에이전트 **Autopilot** 추가, 모델 선택(GPT·Claude·Auto)

## 본문

### 1. Gemini — 13개 새 앱 연동

- **Adobe, Squarespace** 등 13개 앱과 연결되는 플러그인이 추가됐습니다
- AI 회사들이 공통적으로 **유명 서비스 안으로 AI를 밀어 넣는** 방향으로 가고 있습니다 (ChatGPT, Claude, Meta Muse 모두 같은 흐름)

### 2. Google Vids — 누구나 만드는 AI 설명 영상

| 항목 | 내용 |
|------|------|
| 용도 | 비즈니스용 설명 영상, 프레젠테이션 보조 영상 |
| 모델 | **Gemini Omni 1.1 Flash** |
| 가격 | **무료 요금제에서도 사용 가능** |
| 사용법 | "Create AI Video" 메뉴에서 생성 |

### 3. Google Colab — Google AI 요금제에 통합

> **Colab**: 브라우저에서 바로 파이썬 코드를 실행할 수 있는 구글의 무료 개발 환경입니다. 설치 없이 GPU까지 쓸 수 있어 AI 학습·실습에 널리 쓰입니다.

- Google AI 요금제 구독자가 Colab의 **GPU(T4, 상위 H 계열 등)**를 쓸 수 있게 됩니다
- 별도 Colab Pro 결제 없이 AI 구독 하나로 개발 환경까지 해결할 수 있습니다

### 4. Microsoft Copilot 업데이트

| 변경 | 내용 |
|------|------|
| 홈 통합 | 기존 워크스페이스가 **홈**으로 통합 |
| 코드 탭 추가 | 코딩 전용 새 탭 |
| **Autopilot** | Claude Code와 유사한 **클라우드 실행 코딩 에이전트** |
| 모델 선택 | GPT / Claude / Auto 중 선택 |
| Office 연계 | Excel·PowerPoint와 연결해 작업을 바로 전송·실행 |

Microsoft의 강점은 Excel·PowerPoint를 모두 가지고 있다는 점입니다. PowerPoint 안에서 AI로 바로 작업하는 흐름이 자연스럽게 이어집니다.

## 실전 활용 / 팁
- **발표 자료에 영상 추가**: Google Vids 무료 요금제로 PPT 핵심 내용을 설명 영상으로 만들어 보세요
- **AI 학습자라면**: Google AI 요금제 구독 중이라면 Colab GPU로 모델 파인튜닝·실습을 해 보세요
- **Office 중심 회사라면**: Copilot Autopilot으로 코드 작업과 Excel·PowerPoint 보고서를 한 흐름으로 묶어 보세요

## 마무리
구글과 마이크로소프트 모두 **기존에 가진 서비스 자산**(Workspace, Colab, Office)에 AI를 촘촘히 엮고 있습니다. 새 앱을 배우기보다, 이미 쓰는 도구 안에서 AI 기능을 찾아 쓰는 것이 가장 빠른 활용법입니다.
