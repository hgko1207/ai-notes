# 로봇 뉴스 — FLUX 3 Action, 서울 상륙한 휴머노이드 U1, Unitree 손·댄스, 140년 훈련한 축구 로봇

> 한 줄 요약: 이미지 모델 회사 Black Forest Labs가 오픈 웨이트 로봇 모델을 내놓고, 사람처럼 생긴 휴머노이드 U1이 배송을 시작해 서울에도 전시됐으며, Unitree의 정밀한 손과 Skild AI의 축구 로봇까지 로봇 분야가 빠르게 발전하고 있습니다.

## 핵심 요약
- **FLUX 3 Action (Black Forest Labs)**: 화면을 보고 행동하는 오픈 웨이트 로봇 모델, 로봇 벤치마크 **1위**, GTA 플레이·트럭 운전까지
- **휴머노이드 U1**: 눈 깜빡임까지 사람 같은 외형, 실제 배송 시작, **서울 '로봇 파크'** 전시
- **Unitree Dex5S**: 자유도 **22**의 실물 크기 로봇 손, 캔 따기·피아노 연주
- **Unitree 라이브 공연**: 휴머노이드 **19대 + 댄서 12명** 합동 안무
- **Skild AI**: 가상 월드컵에서 **140년 분량**을 훈련한 축구 로봇

## 본문

### 1. FLUX 3 Action — 이미지 회사가 만든 로봇 모델

| 항목 | 내용 |
|------|------|
| 개발사 | Black Forest Labs (FLUX 이미지 모델로 유명) |
| 방식 | 화면(시각 정보)을 보고 판단 → **행동으로 연결** |
| 라이선스 | **오픈 웨이트** |
| 성능 | 로봇 벤치마크 **1위** |
| 데모 | 다양한 로봇 동작, **GTA 플레이**, 트럭 운전 |

이처럼 보는 것과 행동을 하나로 묶는 모델을 **월드 액션 모델(World Action Model)**이라고 부릅니다. 게임과 현실 로봇을 같은 방식으로 조작할 수 있다는 점이 흥미롭습니다.

### 2. 휴머노이드 U1 — 서울에 상륙

- 큰 화제가 됐던 **매우 사람 같은** 휴머노이드, 남성형·여성형 모두 존재
- **눈을 깜빡이는** 등 표정이 자연스럽습니다
- 드디어 **배송 시작** — 주문자들이 실제로 받고 있습니다
- 서울에서도 볼 수 있습니다: G-DRAGON 소속사로 알려진 **갤럭시코퍼레이션**이 운영하는 **'로봇 파크'**에 전시

### 3. Unitree Dex5S — 사람 손 같은 로봇 손

| 항목 | 내용 |
|------|------|
| 자유도(DoF) | **22** |
| 크기 | 실제 손과 **1:1** |
| 시연 | 공 잡기, 콜라 캔 따기, 피아노 연주, 숟가락 쥐기, 종이 자르기 |

> **자유도(Degree of Freedom)**: 로봇이 독립적으로 움직일 수 있는 관절 방향의 수입니다. 사람 손은 약 20~27 자유도로 알려져 있습니다.

Unitree 휴머노이드에 부착하면 훨씬 **정밀한 작업**이 가능해집니다.

### 4. 로봇 백업 댄서의 시대

- Unitree 실물 크기 휴머노이드 **19대**와 댄서 **12명**이 함께한 실시간 라이브 스트리밍 공연
- 사람과 로봇이 섞여 **그룹 안무**를 소화했습니다

### 5. Skild AI — 140년 훈련한 축구 로봇

```
가상 월드컵 시뮬레이션을 대량 병렬 생성
   ↓
로봇이 스스로 경기하며 학습 (누적 140년 분량)
   ↓
실제 로봇에 적용 → 공 빼앗기, 골 넣기
```

사람과 공을 두고 경쟁할 수 있는 수준까지 도달했습니다. **시뮬레이션에서 압축적으로 경험을 쌓는 방식**이 로봇 발전 속도를 끌어올리고 있습니다.

## 실전 활용 / 팁
- **직접 보고 싶다면**: 서울 로봇 파크에서 휴머노이드 U1을 실물로 확인할 수 있습니다
- **로봇 개발자라면**: FLUX 3 Action이 오픈 웨이트로 공개된 만큼, 시뮬레이터·게임 환경에서 먼저 실험해 보세요
- **투자·산업 관점**: 로봇 손(정밀 조작)과 시뮬레이션 학습이 휴머노이드 상용화의 핵심 병목입니다

## 마무리
이번 주 로봇 소식의 공통점은 **"소프트웨어 AI의 방식이 로봇으로 넘어오고 있다"**는 점입니다. 오픈 웨이트 모델, 대규모 시뮬레이션 학습 같은 LLM의 성공 공식이 로봇에도 적용되면서, 로봇 분야 역시 빠르게 발전할 것으로 보입니다.
