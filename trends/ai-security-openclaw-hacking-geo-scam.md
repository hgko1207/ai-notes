# AI 보안 경보 — OpenClaw 해킹 수만 건, GEO를 악용한 가짜 고객센터 사기

> 한 줄 요약: Axios 보도로 OpenClaw 관련 해킹 사건이 수십 건이 아닌 수만 건 규모로 드러났고, AI 답변에 노출되도록 최적화(GEO)한 가짜 고객센터 번호로 피싱하는 새로운 사기 수법이 퍼지고 있습니다.

## 핵심 요약
- **OpenClaw 해킹**: 언론사 Axios 데이터 기준 **수만 건**의 사건 — 알려진 것보다 훨씬 심각
- **제로데이는 피할 수 없음**: 모델이 좋아질수록 공격도 강해지므로 보안도 함께 진화해야 합니다
- **GEO 사기**: 가짜 고객센터 번호·지원 페이지를 대량 생산해 ChatGPT·Gemini 답변에 노출
- **대응 원칙**: AI가 알려 준 연락처는 반드시 **공식 사이트에서 교차 검증**

## 본문

### 1. OpenClaw 해킹 — "생각보다 훨씬 크다"

- 개인 PC에서 상시 실행되는 오픈소스 에이전트 **OpenClaw**는 관련 보안 사고가 여러 차례 보도돼 왔습니다
- Axios가 공개한 데이터에 따르면 사건 수는 **수십 건이 아니라 수만 건**에 달합니다
- 처음엔 경미한 문제로 여겨졌지만, 공격 규모는 전 세계로 번질 수 있는 수준이었다는 분석입니다

#### 왜 에이전트가 위험한가

| 요인 | 설명 |
|------|------|
| 넓은 권한 | 파일·브라우저·메일·결제 등 PC 전체에 접근 |
| 상시 실행 | 24시간 켜져 있어 공격 창구가 항상 열림 |
| 외부 입력 | 웹페이지·메일 속 악성 지시(프롬프트 인젝션)에 노출 |
| 제로데이 | 아직 알려지지 않은 취약점은 방어가 불가능 |

### 2. GEO를 악용한 가짜 고객센터 사기

> **GEO(Generative Engine Optimization)**: 검색엔진 최적화(SEO)의 AI 버전으로, 내 웹사이트가 ChatGPT·Gemini 같은 AI 답변에 인용되도록 최적화하는 기법입니다.

#### 사기 수법

```
1. 사기범이 가짜 고객센터 번호·지원 페이지를 대량 생산
2. AI가 잘 수집하도록 GEO 최적화
3. 사용자가 AI에게 "OO 고객센터 번호 알려줘" 질문
4. AI가 여러 사이트에 반복 등장하는 번호를 "공식 번호"로 판단해 답변
5. 전화 → 피싱
```

여러 사이트에 같은 번호가 나오면 AI는 이를 신뢰도 높은 정보로 오판하기 쉽습니다.

## 실전 활용 / 팁
- **연락처는 공식 채널로 확인**: 고객센터 번호, 환불 링크, 계좌번호는 AI 답변이 아니라 **공식 앱·홈페이지**에서 직접 확인하세요
- **에이전트 권한 최소화**: OpenClaw 같은 로컬 에이전트는 필요한 폴더·계정에만 접근하도록 제한하세요
- **업데이트 즉시 적용**: 에이전트·브라우저·OS 보안 패치를 미루지 마세요
- **결제·송금은 사람이 최종 승인**: 에이전트가 돈을 움직이는 작업은 반드시 수동 승인 단계를 두세요

## 마무리
AI가 똑똑해질수록 공격자도 같은 AI를 씁니다. 에이전트는 편리한 만큼 **공격 표면**도 넓습니다. 당분간은 "AI 답변을 그대로 믿지 않고 교차 검증하는 습관"이 가장 강력한 보안 도구입니다.
