# 9월 말 신모델 모음 — Grok 4.7, 샤오미 MiMo V2.6, Qwen Image 2.1, ZAB Omni, Kling 4.0

> 한 줄 요약: xAI의 가성비 모델 Grok 4.7, 오픈 웨이트 1위에 오른 1조 파라미터 MiMo V2.6, Nano Banana를 넘보는 오픈 이미지 모델 Qwen Image 2.1 등 폐쇄형·오픈 모델이 한꺼번에 쏟아진 한 주였습니다.

## 핵심 요약
- **Grok 4.7**: 같은 가격에 4.6 대비 전반적 성능 향상, SWE 계열 코딩 평가에서 Fable 5.1 이상
- **Xiaomi MiMo V2.6**: 1조 파라미터 오픈 웨이트, 오픈 모델 중 종합 **1위**
- **Qwen Image 2.1**: 오픈 웨이트 이미지 모델, 이미지 편집·다중 참조·투명 배경에 강점
- **ZAB Omni**: 텍스트·이미지·오디오·영상을 모두 받는 실시간 판단용 옴니 모델
- **Kling 4.0 (출시 예정)**: 최대 15개 옴니 레퍼런스, 최대 60초 영상

> ℹ️ 일부 모델명은 영상 자동 자막 기준으로 정리해 실제 표기와 다를 수 있습니다.

## 본문

### 1. Grok 4.7 (xAI)

| 항목 | 내용 |
|------|------|
| 가격 | 이전 4.6과 **동일 가격대** |
| 성능 | 4.6 대비 **전반적으로 크게 향상** |
| 비교 | GPT-5.6 Sol, Fable 5.1과 견줄 만한 수준 |
| 코딩 | SWE(소프트웨어 엔지니어링) 평가에서 **Fable 5.1보다 높음** |

가격 대비 성능이 좋은 모델로 평가됩니다.

### 2. Xiaomi MiMo V2.6 — 오픈 웨이트 1위

- **오픈 웨이트**: 누구나 다운로드해 무료로 사용 가능
- **1조(1T) 파라미터**라 일반 PC에서 돌리기는 어렵습니다
- Artificial Analysis 종합 점수가 Grok 4.7과 **동률 수준**, GPT-6 Sol과도 큰 차이가 없습니다
- 현재 **오픈 웨이트 모델 중 1위**

### 3. Qwen Image 2.1 — "오픈 웨이트판 Nano Banana"

| 기능 | 내용 |
|------|------|
| 이미지 편집 | "이걸 바꿔 줘" 수준의 자연스러운 변환 |
| 다중 참조 | 옷·얼굴 등 여러 이미지를 참조해 캐릭터 생성 |
| 투명 배경 | 투명 PNG 자연스럽게 생성 |
| 성능 | 유료 모델 **Nano Banana보다 높은** 평가 |
| 라이선스 | **상업적 사용은 별도 계약 필요** (다소 엄격) |

#### 오픈 웨이트 출시 후 "공식처럼" 따라오는 것들
오픈 모델이 나오면 커뮤니티가 곧바로 다음을 만들어 냅니다.

```
오픈 웨이트 공개
  → 검열 제거 버전 (거부율 100건 중 5건 수준)
  → 양자화 버전 (12GB VRAM에서 실행)
  → 속도 향상 LoRA (Pruna AI: 생성·편집 최대 3~6.3배 빨라짐)
```

> **양자화(Quantization)**: 모델의 숫자 정밀도를 낮춰 용량과 메모리 사용량을 줄이는 기법입니다.
> **LoRA**: 모델 전체가 아니라 작은 어댑터만 학습·추가해 기능을 바꾸는 경량 기법입니다.

### 4. ZAB Omni (영상 표기) — 실시간 판단용 옴니 모델

- **텍스트·이미지·오디오·영상**을 모두 입력받는 옴니(Omni) 모델
- **Gemma 4 12B 기반 파인튜닝**, Hugging Face에서 다운로드 가능
- 관련 벤치마크 **1위**, GPT-6 Luna보다 높은 성능
- 활용 예: CCTV 영상을 보고 **긴급 상황 즉시 판단**, 레몬 선별처럼 **실시간 분류** 작업

### 5. Kling 4.0 (출시 예정)

- 영상 모델 + 이미지 모델 포함 예정
- Seedance 2.5처럼 **최대 15개 옴니 레퍼런스** 지원
- 영상 길이 **최대 60초**까지 확장

## 실전 활용 / 팁
- **가성비 API 후보에 Grok 4.7 추가**: 코딩 작업 위주라면 비교 테스트해 볼 만합니다
- **자체 호스팅이 필요하면 MiMo V2.6**: 데이터 외부 반출이 어려운 기업은 오픈 웨이트 1위 모델을 검토해 보세요 (대형 GPU 인프라 필요)
- **로컬 이미지 편집은 Qwen Image 2.1**: 12GB VRAM 양자화 버전으로 개인 PC에서도 가능. 단, 상업 이용 전 라이선스를 꼭 확인하세요
- **엣지·실시간 분류는 ZAB Omni**: 12B 규모라 현장 장비에서 CCTV·품질 검사용으로 시도해 볼 수 있습니다

## 마무리
폐쇄형 모델은 가격 대비 성능 경쟁, 오픈 모델은 "1위 탈환" 경쟁이 동시에 벌어지고 있습니다. 특히 오픈 이미지 모델은 출시 며칠 만에 경량화·가속 버전이 나오는 **생태계의 속도**가 가장 큰 강점입니다.
