# GPT-6 Sol·Luna 출시 — Astra급 성능을 싸게, 초저가 경량 모델까지

> 한 줄 요약: OpenAI가 플래그십 GPT-6 Astra에 이어 가성비 모델 Sol(입력 $2/출력 $10)과 초경량 Luna(입력 $0.1/출력 $0.5)를 내놓고, 캐시 입력 최대 90% 할인의 개선된 프롬프트 캐싱까지 추가했습니다.

## 핵심 요약
- **GPT-6 Sol**: Astra와 비슷한 성능, 종합 점수는 약간 낮지만 훨씬 저렴
- **GPT-6 Luna**: 입력 $0.1 / 출력 $0.5, **Gemini 3.5 Flash Lite보다도 저렴**
- **대부분 작업엔 Sol이 좋은 선택**, 대량·단순 작업엔 Luna
- **프롬프트 캐싱 개선**: 캐시 적중률 향상 + 캐시 입력 토큰 **최대 90% 할인**, 캐시 현황 확인 가능

## 본문

### GPT-6 라인업 정리

| 모델 | 포지션 | 입력 (100만 토큰) | 출력 (100만 토큰) |
|------|--------|------------------|------------------|
| GPT-6 Astra | 플래그십 (먼저 출시) | — | — |
| **GPT-6 Sol** | 가성비 주력 | **$2** | **$10** |
| **GPT-6 Luna** | 경량·초저가 | **$0.1** | **$0.5** |

### GPT-6 Sol — "Sol만 써도 Astra에 가깝다"

- Artificial Analysis 기준 **Astra와 대략 비슷한 수준**, 종합 점수는 조금 부족
- Astra나 이전 GPT-5.6 Sol보다 **훨씬 저렴**
- 대부분의 작업을 비용 효율적으로 처리하고 싶다면 가장 무난한 선택입니다

### GPT-6 Luna — 초저가 경량 모델

- 성능은 준수하면서 가격은 크게 낮아졌습니다
- 경쟁 경량 모델인 **Gemini 3.5 Flash Lite보다도 저렴**
- 분류·요약·추출 같은 대량 처리 작업에 적합합니다

### 개선된 프롬프트 캐싱

> **프롬프트 캐싱**: 같은 시스템 프롬프트나 문서를 반복해서 보낼 때, 이미 계산한 부분을 재사용해 비용과 시간을 줄이는 기능입니다.

| 개선 사항 | 효과 |
|----------|------|
| 캐시 적중률(Hit Rate) 향상 | 응답 시간 단축 |
| 캐시 입력 토큰 할인 | **최대 90%** |
| 캐시 현황 확인 | 현재 캐시 상태와 사용 효율을 대시보드로 확인 |

## 실전 활용 / 팁
- **모델 선택 기준**: 품질이 최우선이면 Astra, 일반 업무는 Sol, 대량 배치 처리는 Luna
- **캐싱 활용법**: 긴 시스템 프롬프트·공통 문서를 **프롬프트 앞부분에 고정**해 두면 캐시 적중률이 올라갑니다
- **반복 작업이 많은 서비스**: 챗봇·RAG처럼 같은 맥락을 계속 보내는 서비스라면 캐싱만으로 비용을 크게 줄일 수 있습니다

## 마무리
GPT-6 세대는 "최상위 한 개 + 가성비 라인업"으로 빠르게 정비되고 있습니다. 모델 가격 경쟁이 치열해지면서, 이제는 **어떤 작업에 어떤 등급을 쓸지 설계하는 능력**이 비용을 좌우하게 됐습니다.
